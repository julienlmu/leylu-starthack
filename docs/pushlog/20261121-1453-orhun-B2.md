- What changed:
  - POST /api/price returns every all-in EUR option and the one to quote: 10 start-kit sheets (backend/data/tariffs.json, from the kit thread's normalized file), the live portal for every portal airline on the lane, and the agent's air bids
  - Sheet math per the kit rules: chargeable = max(kg, cbm × 167); freight = max(minimum, rate × billed); fuel + security per billed kg; the own bracket and every higher break are priced, the cheapest wins. Kit worked examples pass (199.36, 319.00, 1607.38, 1160.66)
  - Portal: rate limit is 10 calls/min/team (seen live), rate IDs live ~10 min. Own-bracket call per airline, plus a next-break call only when that break is < 1.5 × the chargeable weight and the minute's budget keeps a reserve; answers cached until valid_until. The backend already asks the portal when the agent PATCHes the rfq, so the price at the 90 s cut-off comes from cache
  - Door-to-port: zone = first 2 postcode digits → origin airport; the trucker bid (leg "pickup", balanced 50/50 choice) is added into one all-in total. No trucker bid → chosen null (the kit has no zone prices)
  - Choice: cheapest (ties → faster), fastest (ties → cheaper); lanes priced only by airline bids use the balanced choice
