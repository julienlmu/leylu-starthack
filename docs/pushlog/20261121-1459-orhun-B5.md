# B5: `make live` runs backend + live agent + Sessions UI all night with auto-restart and logs
- Who: Orhun (tool: Claude Code)
- Branch: orhun/B5-live-runner (stacked on orhun/B4-booking, PR #17)
- What changed:
  - scripts/live.sh (`make live`): starts the backend on :8000 (PORT from .env), waits for /health, then the agent on the live 5U mailbox and the UI on :3000; each process restarts 3 s after it exits; logs in logs/<name>.log; macOS kept awake with caffeinate while it runs; Ctrl-C stops all
  - A lock (logs/live.lock) refuses a second start on the same machine; the header says never to run it on two machines (two agents answer every mail twice)
  - LIVE_AGENT=0 / LIVE_FRONTEND=0 to start only parts (e.g. backend + UI without sending anything)
- Files touched: scripts/live.sh, Makefile, .gitignore (logs/), AGENTS.md, docs/TASKS.md
- Contract/API changes: none
- New env vars / packages: LIVE_AGENT, LIVE_FRONTEND (both default 1). No packages
- How verified: `make check` green. Ran `LIVE_AGENT=0 LIVE_FRONTEND=0 scripts/live.sh`: /health ok, a second start was refused by the lock, killing uvicorn restarted it after 3 s (logged), TERM stopped everything and removed the lock. The live agent was not started (it would answer real mail)
- Known issues / TODO: which machine runs it overnight is the team's call; the machine must stay on power and online; no alert yet when a process keeps crashing (watch logs/ or the UI)
- Heads-up for teammates: whoever runs `make live`, everybody else must not run `make agent` against the live mailbox at the same time
